STEP ③·대시보드

새 공간 추가

대시보드(열기) 왼쪽 공간 목록에서 합니다. 팀당 한 번만.

  1. 왼쪽 + 새 공간 추가 클릭
  2. 공간 이름 · 팀 이름 · 설명 입력, 대표 아이콘 고르기
  3. ② 에서 정한 기본 장치만 체크 (안 쓰는 장치는 체크 해제)
  4. SG90 을 쓰면 서보모터 이름 입력 (예: 환기창, 급식기 뚜껑)
  5. Pico IP 는 비워 두기 (⑦ 에서 입력)
  6. [공간 생성 후 코드 업로드 →] 클릭 → 코드 업로드 창이 열림
✅ 확인 — 공간 목록에 우리 공간이 생겼고, 코드 업로드 창 위쪽에 공간 ID(예: room_mx1abc)가 보입니다.

📌 공간 ID 는 어디서?

우리 공간 오른쪽 ⋮ → 공간 ID 복사. ⑦ Pico 연결 때 필요합니다.

🔁 나중에 다시 열 때

공간 ⋮ → 코드 업로드 · 관리 (④ · ⑥) / Pico 연결 설정 (⑦)

STEP ⑦·선생님과 함께

배선 · 우리 팀 Pico 연결

⑥ 시뮬레이션이 잘 되면 진짜 부품으로 바꿉니다.

  1. 배선: 기본 장치는 정해진 핀(②), 확장 부품은 ② 메모의 핀에 연결
  2. Pico 를 USB 로 전시 PC 에 연결 → CIRCUITPY 드라이브 확인 (예: E:)
  3. 선생님이 펌웨어 설치:
    npm run firmware:bundle -- 공간ID E:\
  4. CIRCUITPY 의 settings.toml 에 Wi-Fi 이름 · 비밀번호 입력 (2.4GHz)
  5. Pico 재부팅 → 시리얼 창에 Pico 2 W IP 확인
  6. 대시보드 우리 공간 ⋮ → Pico 연결 설정 → IP 입력 → [Pico 2 W 연결 저장]
✅ 화면 위쪽에 Pico 2 W (IP) · 연결됨
✅ 센서를 손으로 가리거나 입김을 불면 값이 바뀐다
✅ 3D 물체를 누르면 진짜 서보 · LED 가 움직인다
⚠ 펌웨어 설치 명령이 핀 충돌 · 문법 오류를 알려 주면, 그 메시지를 AI 에게 보내 code.py 를 고친 뒤 다시 업로드 → 다시 설치
🧪 Pico 가 아직 없으면 연습: npm run mock:pico -- --room 공간ID --port 5051 → 연결 설정에 127.0.0.1:5051

기능이 돼도 원색 상자 · 평평한 조명 · 통통 튀는 움직임이면 장난감처럼 보입니다.

✅ 이렇게🚫 하지 말 것
색넓은 면은 차분한 색 (PALETTE), 강조색은 상태에만 2가지 이하원색 · 순흑 · 순회색
재질나무 · 천 · 금속을 MAT 로 구분모든 것이 반짝임
형태1 = 1m 실제 크기 (책상 0.75 · 문 2.0), 둥근 모서리, 바닥에 붙게각진 상자 · 공중에 뜬 물체 · 엉뚱한 크기
구성주인공 1개 + 소품 3~5개, 여백 남기기물체 수백 개 · 조명 추가로 하얗게
움직임감속하며 멈춤, 센서 · 클릭에 반응할 때만bounce · 계속 빙빙 도는 장식
배지같은 모양 5개 이하, 상태는 색 + 글자모든 물체에 이름표 · 겹침 · 색으로만
디자인 규칙 블록 (자세한 버전)④ 짧은 규칙 대신 아이디어 칸 끝에
[디자인 규칙 — 전문 디자인 수준으로 만들어 주세요]
(플랫폼 SDK 의 디자인 킷 PALETTE · MAT · DataPin · HoverLift · useSmoothValue 를 사용합니다)
1. 색: 벽 · 바닥 · 가구 같은 넓은 면은 PALETTE 의 차분한 색(wall, oak, linen, sage, sand, walnut)을 씁니다.
   원색(#FF0000 · #00FF00 · #0000FF) · 순흑(#000) · 순회색은 쓰지 않습니다.
   강조색(PALETTE.ok · warn · alert · info)은 상태 · 데이터 표시에만, 한 화면에 2가지 이하로 씁니다.
2. 재질: 모든 물체에 MAT 프리셋을 씁니다.
   나무 MAT.oak/walnut, 패브릭 MAT.linen/sage, 세라믹 MAT.ceramic, 금속 MAT.brushedMetal, 식물 MAT.plant,
   유리 <meshPhysicalMaterial {...MAT.glass} />. 표시등 · 화면만 MAT.glow(color, on) · MAT.screen(color) 로 빛나게 합니다.
3. 형태 · 비례: 1 = 1m 실제 크기 (책상 높이 0.75, 의자 좌판 0.45, 문 2.0, 천장 3.0).
   가구는 drei RoundedBox(radius 0.03~0.08)로 둥글게, 모든 물체는 바닥이나 벽에 붙게 (공중에 뜨지 않게).
4. 구성: 주인공 오브젝트 1개를 가운데에 두고, 생활감을 주는 소품(화분 · 책 · 쿠션 등) 3~5개를 여백을 두고 배치합니다.
5. 조명: 플랫폼 조명 · 환경광을 그대로 쓰고, pointLight 는 2개 이하로 합니다.
6. 모션: useFrame + THREE.MathUtils.damp 로 감속하며 멈추게 합니다.
   bounce · elastic · 계속 도는 장식은 넣지 않고, 센서 값 · 명령 결과에 반응하는 움직임만 넣습니다.
7. 데이터: 수치는 <DataPin sensor={...} /> 로 통일하고, 배지는 5개 이하 · 서로 겹치지 않게 배치합니다.
   상태는 색 + 글자로 함께 보여 줍니다.
8. 상호작용: 클릭할 물체는 <HoverLift onClick={...}> 로 감싸고 sendCommand 를 연결합니다.
9. 견고성: 센서 값으로 움직이는 부분은 useSmoothValue 로 부드럽게 합니다 (끊기면 마지막 값 유지).
10. 성능: useFrame 안에서 new THREE.Vector3() 등 객체를 만들지 않습니다.
    같은 물체 10개 이상은 drei <Instances> 로, 전체 오브젝트는 80개 이하로 합니다.
    외부 모델 · 텍스처 · drei Text 는 쓰지 않고, 글자는 <Html> 로 씁니다.

이름 (@/core/sdk)하는 일

MAT재질 (oak · linen · ceramic · brushedMetal · glass · glow · screen)

마스코트고양이 집사 · 젖소 농부 · 작업 로봇 · 교복 학생 — 천천히 걷고 누르면 인사
예시 코드: 수족관 수조킷 함께 쓰기
import React, { useRef } from 'react';
import * as THREE from 'three';
import { useFrame } from '@react-three/fiber';
import { RoundedBox } from '@react-three/drei';
import { MAT, PALETTE, DataPin, HoverLift, useSmoothValue, useCustomSensor, sendCommand } from '@/core/sdk';

export default function Scene({ isModalOpen = false }: { isModalOpen?: boolean }) {
  const level = useCustomSensor('water_level');          // 0~100 %
  const smooth = useSmoothValue(level?.value, { initial: 50 });
  const water = useRef<THREE.Mesh>(null);
  useFrame(() => {
    if (!water.current) return;
    const k = THREE.MathUtils.clamp(smooth.current / 100, 0.05, 1); // 범위 밖 값은 잘라서
    water.current.scale.y = k;
    water.current.position.y = 0.45 + (1.2 * k) / 2;
  });
  return (
    <group>
      <mesh rotation={[-Math.PI / 2, 0, 0]} receiveShadow>
        <planeGeometry args={[7, 7]} /><meshStandardMaterial {...MAT.oak} />
      </mesh>
      <RoundedBox args={[2.4, 0.45, 1.2]} radius={0.05} position={[0, 0.225, 0]} castShadow>
        <meshStandardMaterial {...MAT.walnut} />
      </RoundedBox>
      <mesh ref={water} position={[0, 1.05, 0]}>
        <boxGeometry args={[2.2, 1.2, 1.0]} />
        <meshStandardMaterial color={PALETTE.info} transparent opacity={0.35} roughness={0.1} />
      </mesh>
      <mesh position={[0, 1.05, 0]}>
        <boxGeometry args={[2.3, 1.25, 1.1]} /><meshPhysicalMaterial {...MAT.glass} />
      </mesh>
      <HoverLift position={[1.5, 0.45, 0]} onClick={() => sendCommand('feed', true)}>
        <mesh castShadow><cylinderGeometry args={[0.12, 0.12, 0.25, 32]} /><meshStandardMaterial {...MAT.ceramic} /></mesh>
      </HoverLift>
      <DataPin position={[-1.4, 0.45, 0.4]} label="수위" sensor={level} isModalOpen={isModalOpen} />
    </group>
  );
}
