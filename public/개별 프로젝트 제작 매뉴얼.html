STEP ③·대시보드

새 공간 추가

대시보드(열기) 왼쪽 공간 목록에서 합니다. 팀당 한 번만.

  1. 왼쪽 + 새 공간 추가 클릭
  2. 공간 이름 · 팀 이름 · 설명 입력, 대표 아이콘 고르기
  3. ② 에서 정한 기본 장치만 체크 (안 쓰는 장치는 체크 해제)
  4. SG90 을 쓰면 서보모터 이름 입력 (예: 환기창, 급식기 뚜껑)
  5. Pico IP 는 비워 두기 (⑦ 에서 입력)
  6. [공간 생성 후 코드 업로드 →] 클릭 → 코드 업로드 창이 열림
✅ 확인 — 공간 목록에 우리 공간이 생겼고, 코드 업로드 창 위쪽에 공간 ID(예: room_mx1abc)가 보입니다.

STEP ⑦·선생님과 함께

배선 · 우리 팀 Pico 연결

⑥ 시뮬레이션이 잘 되면 진짜 부품으로 바꿉니다.

  1. 배선: 기본 장치는 정해진 핀(②), 확장 부품은 ② 메모의 핀에 연결
  2. Pico 를 USB 로 전시 PC 에 연결 → CIRCUITPY 드라이브 확인 (예: E:)
  3. 선생님이 펌웨어 설치:
    npm run firmware:bundle -- 공간ID E:\
  4. CIRCUITPY 의 settings.toml 에 Wi-Fi 이름 · 비밀번호 입력 (2.4GHz)
  5. Pico 재부팅 → 시리얼 창에 Pico 2 W IP 확인
  6. 대시보드 우리 공간 ⋮ → Pico 연결 설정 → IP 입력 → [Pico 2 W 연결 저장]
✅ 화면 위쪽에 Pico 2 W (IP) · 연결됨
✅ 센서를 손으로 가리거나 입김을 불면 값이 바뀐다
✅ 3D 물체를 누르면 진짜 서보 · LED 가 움직인다
⚠ 펌웨어 설치 명령이 핀 충돌 · 문법 오류를 알려 주면, 그 메시지를 AI 에게 보내 code.py 를 고친 뒤 다시 업로드 → 다시 설치
🧪 Pico 가 아직 없으면 연습: npm run mock:pico -- --room 공간ID --port 5051 → 연결 설정에 127.0.0.1:5051
